This section provides instructions for an Android developer to setup OneLink (deep linking and deferred deep linking) to work in the app.

There are three stages involved in the setup: 

1. [Initial app setup](https://dev.appsflyer.com/docs/initial-setup-for-deep-linking-and-deferred-deep-linking)
2. [Direct deep linking](https://dev.appsflyer.com/docs/deep-linking-existing-app-users-to-specific-content)
3. [Deferred deep linking](https://dev.appsflyer.com/docs/deferred-deep-linking-new-users-to-specific-content-inside-your-app)
