This section provides instructions for an Android developer to setup OneLink (deep linking and deferred deep linking) to work in the app.

There are several stages involved in the setup: 

1. [Initial app setup](https://dev.appsflyer.com/docs/initial-setup-for-deep-linking-and-deferred-deep-linking)
2. [Unified deep linking (UDL)](https://dev.appsflyer.com/hc/docs/unified-deep-linking-udl)

**Note:** Customers already using OneLink may be using the [legacy methods](https://dev.appsflyer.com/hc/docs/android-legacy-apis) for deep linking and deferred deep linking, instead of UDL.
