This section provides instructions for an iOS developer to setup OneLink (deep linking and deferred deep linking) to work in the app.

There are several stages involved in the setup: 

1. [Initial app setup](https://dev.appsflyer.com/docs/initial-setup-2)
2. [Unified deep linking (UDL)](https://dev.appsflyer.com/hc/docs/unified-deep-linking-udl-1)

**Note:** Customers already using OneLink may be using the [legacy methods](https://dev.appsflyer.com/hc/docs/ios-legacy-apis) for iOS deep linking and deferred deep linking, instead of UDL.
