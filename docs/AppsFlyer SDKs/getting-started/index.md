## Getting started with AppsFlyer SDKs

AppsFlyer empowers marketers and helps them make better decisions. This is done by providing marketers with powerful tools that solve real pain points, including cross-platform attribution, mobile and web analytics, deep linking, fraud detection, privacy management and preservation, and much more.

The AppsFlyer Software Development Kits (SDKs) and plugins are your primary way to tap into this ecosystem. Pick the path below that fits how you like to work.

> 📘 Note
>
> AppsFlyer supports only the HTTPS protocol for all incoming SDK traffic.

## Pick your path

Start with the wizard or the MCP server to save time, or browse by platform for the full manual guides.

### SDK integration wizard

Answer a few questions about your app and platform, and [Developer Journey](https://dj.dev.appsflyer.com/?utm_source=devhub&utm_medium=dj-getting-started) generates the code for installation, integration, in-app events, and deep linking. Currently supports Android, iOS, React Native, and Flutter.

### Integrate with the AppsFlyer SDK MCP

Use the AppsFlyer SDK MCP server with Cursor, GitHub Copilot, or Codex to offload most of the integration work. [See the AI integration guide](doc:integrate-sdk-with-ai). Currently supports Android and iOS.
