**At a glance**: Use URIs to get your aggregated data reports in CSV files.

> 🔑 Authentication 
> 
> An API V2 token (bearer token) is required to use Pull API. 
> The admin gets the V2 token in the [dashboard](https://support.appsflyer.com/hc/en-us/articles/360004562377)

**Endpoints and methods:**

The Pull API aggregated includes the following methods:

- [Partners](ref:get_app-id-partners-report-v5-1) (GET)
- [Partners daily](ref:get_app-id-partners-by-date-report-v5-1) (GET)
- [Daily](ref:get_app-id-daily-report-v5-1) (GET)
- [Geo](ref:get_app-id-geo-report-v5-1) (GET)
- [Geo daily](ref:get_app-id-geo-by-date-report-v5-1) (GET)
