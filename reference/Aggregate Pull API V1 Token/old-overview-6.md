**At a glance**: Use URIs to get your aggregated data reports in CSV files.

> 🔑 Authentication 
> 
> A Pull API authentication token (key) is required to use Pull API. 
> Admins can get the token from the API Tokens page. [API Tokens page](https://hq1.appsflyer.com/account/api-tokens)

**Endpoints and methods:**

The Pull API aggregated includes the following methods:

- [Partners](ref:get_app-id-partners-report-v5)   (GET)
- [Partners daily](ref:get_app-id-partners-by-date-report-v5)  (GET)
- [Daily](ref:get_app-id-daily-report-v5)  (GET)
- [Geo](ref:get_app-id-geo-report-v5)  (GET)
- [Geo daily](ref:get_app-id-geo-by-date-report-v5) (GET)
