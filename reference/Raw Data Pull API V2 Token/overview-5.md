**At a glance**: Use URIs to get your raw data reports in CSV files.

> 🔑 Authentication 
> 
> A Pull API authentication token (key) is required to use Pull API. 
> Get the API token from your AppsFlyer admin. See [API token instructions](https://support.appsflyer.com/hc/en-us/articles/360004562377)

**Endpoints and methods:**

You can create a variety of reports with the Pull API raw data. For example:

- [Raw data non-organic Installs](https://dev.appsflyer.com/hc/reference/get_app-id-installs-report-v5) (GET)
- [Raw data organic Installs](https://dev.appsflyer.com/hc/reference/get_-app-id-organic-installs-report-v5)(GET)
- [Ad Revenue raw data Attributed](https://dev.appsflyer.com/hc/reference/get_app-id-ad-revenue-raw-v5) (GET)
- [Protect360 fraud Installs](https://dev.appsflyer.com/hc/reference/get_app-id-blocked-installs-report-v5) (GET)
- [Install postbacks](https://dev.appsflyer.com/hc/reference/get_app-id-postbacks-v5) (GET)
